# Дизайн-система ESEO

Источник: Figma «eseo», страница «Design System». Все значения лежат в `src/styles/tokens.css`, наглядно они показаны на странице `/styleguide`.

## Как устроены цвета

Цвета хранятся в два слоя:

1. **Палитра** (`--palette-*`) — цвета ровно как в Figma: `brand/600`, `gray/950` и т. д. Используется только внутри `tokens.css`.
2. **Токены по назначению** (`--color-*`) — их используют компоненты. Например, `brand` — основной синий для кнопок, `text-secondary` — второстепенный текст.

Чтобы поменять цвет на всём сайте, поменяйте значение в палитре. Чтобы поменять цвет у одной роли (например, у всего второстепенного текста), поменяйте, на какой цвет палитры ссылается токен.

Встроенные цвета Tailwind (`blue-500` и т. п.) отключены, доступны только наши токены.

## Текст

Шрифт Inter хранится в `public/fonts`, Google Fonts не используется.

Крупные размеры (`display-*`, `heading-*`, `giant-*`) плавно уменьшаются на маленьких экранах: значение в Figma — это размер на десктопе (1440px), на телефоне (390px) размер меньше. Мелкие размеры (`body`, `label`, `caption`, `button`) одинаковы на всех экранах.

## Отступы

В Figma нет переменных для отступов, поэтому используется шаг 4px: `p-1` = 4px, `p-4` = 16px, `gap-6` = 24px. Расстояние между секциями задаёт токен `--space-section`.

## Блоки с фиксированным размером

Пока нет. Если какой-то блок должен иметь точный размер в пикселях, он записывается сюда.

## Что пока не взято из Figma

- **Ширина контейнера страницы** (`--container-page`) — временное значение, уточним по странице Home.
- **Длительность анимаций** — в Figma не заданы, стоят стартовые значения.
- **Стили `typo/mockup/*`** (8–22px) — для мини-интерфейсов на иллюстрациях. Добавим, когда дойдём до этих компонентов.
